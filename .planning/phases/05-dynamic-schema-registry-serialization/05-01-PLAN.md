<task name="implement_schema_converters" type="auto">
  <files>src/postoffice/schema/converters.py</files>
  <action>
    Create `src/postoffice/schema/converters.py`:
    1. Implement Confluent wire format framing:
       - `encode_wire_format(payload: bytes, schema_id: int) -> bytes`: Prepend `b'\x00' + struct.pack('>I', schema_id)`.
       - `decode_wire_format(data: bytes) -> tuple[int, bytes]`: Validate `data[0] == 0`, extract `struct.unpack('>I', data[1:5])[0]`, return `(schema_id, data[5:])`.
    2. Implement `SchemaConverter`:
       - `__init__(registry: BaseSchemaRegistry)`
       - `deserialize(payload: bytes, format_type: str, schema_name: Optional[str] = None, wire_format: bool = False) -> dict`:
         - If `wire_format`: strip header and use `schema_id` from header if `schema_name` not provided.
         - If `format_type == 'json'`: `json.loads(payload.decode('utf-8'))`.
         - If `format_type == 'avro'`: resolve schema from registry, `fastavro.schemaless_reader(io.BytesIO(payload), schema_entry.parsed_schema)`.
         - If `format_type == 'protobuf'`: resolve message class, parse from protobuf binary, convert to dict via `json_format.MessageToDict()`.
       - `serialize(record: dict, format_type: str, schema_name: Optional[str] = None, wire_format: bool = False) -> bytes`:
         - If `format_type == 'json'`: `json.dumps(record).encode('utf-8')`.
         - If `format_type == 'avro'`: resolve schema from registry, write via `fastavro.schemaless_writer`. If `wire_format`, prepend wire header with `schema_entry.schema_id`.
         - If `format_type == 'protobuf'`: resolve message class, populate from record dict via `json_format.ParseDict`, serialize to bytes. If `wire_format`, prepend wire header.
  </action>
  <verify>
    <command>PYTHONPATH=src .venv/bin/python -c "from postoffice.schema.converters import SchemaConverter, encode_wire_format, decode_wire_format; b = encode_wire_format(b'abc', 42); sid, payload = decode_wire_format(b); assert sid == 42 and payload == b'abc'"</command>
  </verify>
</task>
