<task name="implement_topic_trie_module" type="auto">
  <files>src/postoffice/trie.py</files>
  <action>
    Create `src/postoffice/trie.py`:
    1. Define `TrieNode`:
       - `children: Dict[str, TrieNode]`
       - `wildcard_single: Optional[TrieNode]` (for `+`)
       - `wildcard_multi: List[Any]` (for `#`)
       - `routes: List[Any]` (exact terminal routes)
    2. Define `TopicTrie`:
       - `__init__()`: initialize `self.root = TrieNode()` and `self._count = 0`.
       - `insert(topic_pattern: str, route_data: Any)`:
         - Validate topic pattern: `#` can only appear as the last segment (e.g. `a/#` or `#`). Raise `ValueError` if `#` appears anywhere else (e.g. `a/#/b`).
         - Split pattern by `/`.
         - Traverse/build tree:
           - If segment == `+`: use/create `node.wildcard_single`.
           - If segment == `#`: append `route_data` to `node.wildcard_multi`, increment `_count`, and return.
           - Else: use/create `node.children[segment]`.
         - At end of segments (if not ending in `#`), append `route_data` to `node.routes`, increment `_count`.
       - `match(topic: str) -> List[Any]`:
         - Split incoming `topic` by `/`.
         - DFS search collecting all matching terminal `routes` and `wildcard_multi` entries.
         - Return deduplicated or ordered list of matching route entries.
       - `clear()`:
         - Reset `self.root = TrieNode()` and `self._count = 0`.
       - `__len__() -> int`: return `self._count`.
  </action>
  <verify>
    <command>PYTHONPATH=src .venv/bin/python -c "from postoffice.trie import TopicTrie; t = TopicTrie(); t.insert('a/+/c', 1); t.insert('a/#', 2); assert set(t.match('a/b/c')) == {1, 2}"</command>
  </verify>
</task>

  <files>src/postoffice/router.py</files>
  <read_first>src/postoffice/router.py</read_first>
  <action>
    Update `src/postoffice/router.py`:
    1. Import `TopicTrie` from `postoffice.trie`.
    2. In `Router.__init__`:
       - Initialize `self.client_tries: Dict[str, TopicTrie] = {}`.
       - Retain `self.routes` dictionary for backward-compatibility / inspection if needed, or sync with trie.
    3. In `Router.add_route`:
       - If `source_client not in self.client_tries`: create `self.client_tries[source_client] = TopicTrie()`.
       - Insert `route_config` into `self.client_tries[source_client].insert(source_topic, route_config)`.
       - Also update `self.routes[(source_client, source_topic)]` for backward compatibility.
    4. In `Router.route`:
       - Instead of looping over all routes in `self.routes`, look up `self.client_tries.get(source_client)`.
       - If trie exists, query `matching_routes = trie.match(source_topic)`.
       - Process fanout coordinator and publish dispatches as before.
    5. Maintain `Router._topic_match` as helper for backwards compatibility.
  </action>
