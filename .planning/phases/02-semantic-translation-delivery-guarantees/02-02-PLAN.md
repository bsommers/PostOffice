    src/postoffice/plugins/mqtt_client.py
  </read_first>
  <action>
    1. Update `KafkaClient.publish`:
       Accept `on_confirm=None`, `on_error=None`.
       In `delivery_report(err, msg)`:
       ```python
       def delivery_report(err, msg):
           if err is not None:
               logger.error(f"Message delivery failed: {err}")
               if on_error:
                   on_error(err)
           else:
               if on_confirm:
                   on_confirm()
       ```
    2. Update `AmqpClient`:
       - In `publish`: accept `on_confirm=None`, `on_error=None`. In `_publish`:
         ```python
         try:
             self.channel.basic_publish(...)
             if on_confirm:
                 on_confirm()
         except Exception as e:
             if on_error:
                 on_error(e)
             raise
         ```
       - In `subscribe`: track if `auto_ack` is False.
       - In `_on_message`: pass `ack_fn=lambda: ch.basic_ack(delivery_tag=method.delivery_tag)` and `nack_fn=lambda requeue=True: ch.basic_nack(delivery_tag=method.delivery_tag, requeue=requeue)` when manual acking is enabled (`not self.auto_ack` or message property).
    3. Update `MqttClient.publish`:
       Accept `on_confirm=None`, `on_error=None`.
       ```python
       info = self.client.publish(topic, message, qos=qos, retain=retain)
       if on_confirm:
           # For QoS 0 or synchronous mock, trigger immediately; for QoS 1/2 or if info provided
           on_confirm()
       ```
  </action>
  <verify>
    <command>PYTHONPATH=src .venv/bin/python -m unittest discover tests/</command>
  </verify>
</task>

  <action>
    Create `tests/test_delivery_guarantees.py` with mock-based unit tests for:
    1. `test_single_target_ack`: Ingress client calls `on_message` with `ack_fn` and `nack_fn`. Target client publish calls `on_confirm()`. Verify `ack_fn` called, `nack_fn` not called.
    2. `test_single_target_nack_on_error`: Target client publish calls `on_error()`. Verify `nack_fn(requeue=True)` called, `ack_fn` not called.
    3. `test_fanout_latch_all_succeed`: 1 source routes to 2 targets. `ack_fn` called only after both targets invoke `on_confirm()`.
    4. `test_fanout_latch_any_fail`: 1 source routes to 2 targets. Target 1 confirms, Target 2 errors. Verify `nack_fn` called and `ack_fn` not called.
    5. `test_semantic_translation_mqtt_to_amqp`:
       - Ingress QoS 1 -> target AMQP defaults `delivery_mode=2`
       - Ingress QoS 0 -> target AMQP defaults `delivery_mode=1`
    6. `test_semantic_translation_amqp_to_mqtt`:
       - Ingress AMQP `delivery_mode=2` -> target MQTT defaults `qos=1`
       - Ingress AMQP `delivery_mode=1` -> target MQTT defaults `qos=0`
    7. `test_semantic_translation_explicit_override`:
       - Explicit route `delivery_mode` overrides source QoS translation.
       - Explicit route `qos` overrides source `delivery_mode` translation.
    8. `test_kafka_delivery_report_triggers_callbacks`:
       - Call `KafkaClient.publish` with `on_confirm` / `on_error` and verify mock `Producer.produce` callback invocation.
