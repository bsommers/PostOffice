<task name="wire_dlq_into_router_and_app" type="auto">
  <files>
    src/postoffice/router.py
    src/postoffice/app.py
  </files>
  <read_first>
    src/postoffice/router.py
    src/postoffice/app.py
  </read_first>
  <action>
    1. Update `Router`:
       - Add `self.default_dlq_broker: Optional[str] = None` and `self.default_dlq_topic: Optional[str] = None`.
       - Add method `set_dlq(broker_name: str, topic: str)`.
       - Support `dlq_broker` and `dlq_topic` in `add_route()`.
       - Add helper `_route_to_dlq(source_broker, source_topic, payload, error, target_dlq_broker, target_dlq_topic, ack_fn, nack_fn)`:
         - Anti-recursion check: If `source_broker == target_dlq_broker and source_topic == target_dlq_topic`: log critical warning and drop / invoke `nack_fn`.
         - Format envelope via `format_dlq_payload`.
         - If `target_dlq_broker in self.clients`:
           - Publish to `target_dlq_broker` on `target_dlq_topic`.
           - Record metric `record_dlq`.
           - Call `ack_fn()` (if provided) because message was safely DLQed.
         - Else:
           - Call `nack_fn(requeue=True)`.
       - In `route()`:
         - When no matching routes found:
           - If DLQ configured: call `_route_to_dlq`.
           - Else: call `ack_fn()` if provided.
         - When downstream publish fails or reports `on_error`:
           - If DLQ configured for the route (or default DLQ): call `_route_to_dlq`.
           - Else: coordinator triggers `nack_fn`.
    2. Update `PostOffice`:
       - Add `set_dlq(broker_name: str, topic: str)` delegating to `Router.set_dlq`.
       - Support `dlq_broker` and `dlq_topic` in `PostOffice.__init__`.
       - Pass `dlq_broker` and `dlq_topic` in `add_route`.
  </action>
  <verify>
    <command>PYTHONPATH=src .venv/bin/python -m unittest discover tests/</command>
  </verify>
</task>
