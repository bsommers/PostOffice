# Quick Task 261102-p3a: Native Data Plane Worker Core (P3-1)

## Goal
Implement the Phase 3 Native Data Plane worker core in `native/libpostoffice`:
1. **D9 HMAC-SHA256 Signing & Control-Plane Action Validator (`src/signing.rs`):**
   - Pure-Rust SHA-256 and HMAC-SHA256 implementation (zero external crates).
   - Supports `POSTOFFICE_EVENT_KEYS` (`kid1:secret1,kid2:secret2`), domain-separated verification (`event\0`, `state\0{hash}\0{field}\0`, `version\0{ver}`), and signing modes `off`, `observe`, `enforce`.
   - Control-plane action validator (`add_broker`, `add_route`, `add_subscription`, `update_broker_security`, `set_ingress`, `clear_state`) matching `src/postoffice/validation.py` and `conformance/vectors/control_plane_signing.json`.
2. **Native Router Core, DLQ Budget, & Metrics (`src/engine.rs`):**
   - `Engine` (`po_engine_t`) combining per-broker `TopicTrie`, `Firewall`, `CodecRegistry`, `MemoryGovernor`, `BudgetedDlq` (`format_dlq_payload`, `dlq_fingerprint`, oversize metadata-only fallback, deduplication window, msg/byte token buckets, anti-recursion check), `unroutable_policy` (`nack`, `dlq`, `drop`), semantic translation (`qos` <-> `delivery_mode`), fan-out coordination, and `ExponentialBackoff`.
   - `MetricsRegistry` with `LabelGuard` (`max_values=100`, overflow `"other"`) rendering standard Prometheus text exposition format and serving `/metrics`, `/healthz`, and `/readyz` over HTTP (`127.0.0.1` default).
3. **Redis RESP2 Subscribe-Before-Snapshot Client & Worker Binary (`src/redis_sync.rs`, `src/bin/postoffice-worker.rs`):**
   - RESP2 client implementing T7 convergent state sync: `SUBSCRIBE postoffice:config_updates` (confirmed before snapshot), bounded event buffer (`max_buffered=10,000`), `GET postoffice:version`, `HGET postoffice:version_sigs`, `HGETALL postoffice:{brokers,routes,subscriptions,ingress}`, monotonic version ordering (`applied`, `stale`, `gap`), and reconnect/gap resync with `ExponentialBackoff`.
4. **C ABI & Python FFI Bridge (`include/postoffice.h`, `src/postoffice/native.py`, `tests/test_phase3_native_worker_core.py`):**
   - Expose `po_engine_*` and `po_signing_*` in `include/postoffice.h` and `src/postoffice/native.py`.
   - Verify 100% conformance and RESP2 convergence in `tests/test_phase3_native_worker_core.py`.
