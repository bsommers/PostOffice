<task name="integrate_circuit_breaker_in_router_and_app" type="auto">
  <files>
    src/postoffice/router.py
    src/postoffice/app.py
  </files>
  <action>
    1. In `Router`:
       - Add `self.circuit_breakers: Dict[str, CircuitBreaker] = {}`.
       - Add `configure_circuit_breaker(self, broker_name: str, failure_threshold: int = 5, recovery_timeout: float = 30.0, time_fn=time.monotonic) -> CircuitBreaker`.
       - In `route()`:
         - If `target_client` has an active `CircuitBreaker`:
           - If `not breaker.allow_request()`:
             - Record metric `self.metrics.record_error(source_client, "circuit_open")`.
             - Attempt ring-buffer failover on `target_obj = self.clients[target_client]` via `target_obj.buffer_publish(target_topic, out_message, on_confirm=..., on_error=..., **publish_kwargs)`.
             - If `buffer_publish` returns `False` (buffering disabled), trigger `CircuitBreakerOpenError` handling (via `coordinator.on_error(exc)` or `_route_to_dlq`).
           - If `breaker.allow_request()` is `True`:
             - Wrap `on_confirm` and `on_error` callbacks passed to `publish()` so `on_confirm` calls `breaker.record_success()` (and if `record_success()` returns `True` indicating recovery from `HALF_OPEN`, flushes `target_obj.flush_publish_buffer()`) and `on_error` / synchronous exception calls `breaker.record_failure()`.
    2. In `PostOffice`:
       - Add `configure_circuit_breaker(self, broker_name: str, failure_threshold: int = 5, recovery_timeout: float = 30.0) -> CircuitBreaker` delegating to `self.router.configure_circuit_breaker`.
       - Support optional `circuit_breaker_threshold: Optional[int] = None` and `circuit_breaker_timeout: float = 30.0` in `add_broker()`.
  </action>
  <verify>
    <command>PYTHONPATH=src .venv/bin/python -m unittest discover tests/</command>
  </verify>
</task>
