<task name="implement_plugin_security_reload" type="auto">
  <files>
    src/postoffice/base_client.py
    src/postoffice/plugins/mqtt_client.py
    src/postoffice/plugins/amqp_client.py
    src/postoffice/plugins/kafka_client.py
  </files>
  <action>
    1. In `BaseClient`: add `reload_security(self, security_config: Any) -> None` method.
    2. In `MqttClient` (and inherited by `NanoMqClient`):
       - Extract `_apply_security_to_client(self)` helper used by both `__init__` and `reload_security`.
       - In `reload_security(self, security_config)`:
         - Check if currently connected (`was_connected = self.client.is_connected()`).
         - Update `self.security = ensure_security_config(security_config)`.
         - Update port if switching plaintext <-> TLS default ports (1883<->8883, or 1884<->8884 for NanoMQ).
         - If `was_connected`: call `self.disconnect()`.
         - Recreate `self.client = mqtt.Client(mqtt.CallbackAPIVersion.VERSION2, client_id=self.name)`, bind callbacks, call `self._apply_security_to_client()`.
         - If `was_connected`: call `self.connect()`.
    3. In `AmqpClient`:
       - In `reload_security(self, security_config)`:
         - Check if currently connected (`was_active = bool(self.connection and self.connection.is_open) or bool(self.thread and self.thread.is_alive())`).
         - Update `self.security = ensure_security_config(security_config)`.
         - Update `self.user` and `self.password` from `self.security` if provided, and adjust port if 5672<->5671.
         - If `was_active`: call `self.disconnect()`, clear `self._stop_event` and `self._connected_event`, and call `self.connect()`.
    4. In `KafkaClient`:
       - In `reload_security(self, security_config)`:
         - Check `was_active = bool(self.producer is not None or self.consumer is not None)`.
         - Update `self.security = ensure_security_config(security_config)`.
         - If `was_active`:
           - Call `self.disconnect()`.
           - Clear `self._stop_event`.
           - Under `self._subscribe_lock`, move all topics from `self.subscribed_topics` into `self._pending_subscriptions` and clear `self.subscribed_topics` so the new Consumer re-subscribes automatically.
           - Call `self.connect()`.
  </action>
  <verify>
    <command>PYTHONPATH=src .venv/bin/python -m unittest discover tests/</command>
  </verify>
</task>
