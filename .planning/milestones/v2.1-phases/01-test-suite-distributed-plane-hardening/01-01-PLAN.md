<task name="add_postoffice_reset_method" type="auto">
  <files>src/postoffice/app.py</files>
  <read_first>src/postoffice/app.py</read_first>
  <action>
    Add a `reset()` method to the `PostOffice` facade class in `src/postoffice/app.py`:
    ```python
    def reset(self) -> None:
        """
        Stops and cleans up all active brokers, and clears all routes and client registrations.
        Resets the PostOffice instance to an unconfigured state.
        """
        logger.info("Resetting PostOffice state...")
        self.stop()
        self.brokers.clear()
        self.router.routes.clear()
        self.router.clients.clear()
        self.is_running = False
    ```
  </action>
  <verify>
    PYTHONPATH=src .venv/bin/python -c "from postoffice.app import PostOffice; po = PostOffice(); po.reset(); assert len(po.brokers) == 0"
  </verify>
  <acceptance_criteria>
    - `PostOffice` has `reset()` method
    - Calling `reset()` stops connections, clears `brokers`, `router.routes`, `router.clients`, and sets `is_running = False`
  </acceptance_criteria>
</task>
