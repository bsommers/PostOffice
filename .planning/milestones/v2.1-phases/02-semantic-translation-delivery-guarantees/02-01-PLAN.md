    1. Add thread-safe `_FanoutCoordinator`:
       ```python
       import threading

       class _FanoutCoordinator:
           """Coordinates asynchronous delivery confirmations across multiple target broker publishes."""
           def __init__(self, expected_count: int, ack_fn: Optional[Callable[[], None]], nack_fn: Optional[Callable[[bool], None]]):
               self.remaining = expected_count
               self.ack_fn = ack_fn
               self.nack_fn = nack_fn
               self.lock = threading.Lock()
               self.failed = False

           def on_confirm(self):
               with self.lock:
                   if self.failed:
                       return
                   self.remaining -= 1
                   if self.remaining == 0 and self.ack_fn:
                       self.ack_fn()

           def on_error(self, exc: Exception):
               with self.lock:
                   if not self.failed:
                       self.failed = True
                       if self.nack_fn:
                           self.nack_fn(requeue=True)
       ```
    2. Add semantic translation helper `_translate_semantics(source_kwargs: dict, target_kwargs: dict) -> dict`:
       - If `delivery_mode` not in `target_kwargs`:
         - If `source_kwargs.get("qos") in (1, 2)`: set `delivery_mode = 2`
         - Else if `source_kwargs.get("qos") == 0`: set `delivery_mode = 1`
       - If `qos` not in `target_kwargs`:
         - If `source_kwargs.get("delivery_mode") == 2`: set `qos = 1`
         - Else if `source_kwargs.get("delivery_mode") == 1`: set `qos = 0`
    3. Update `Router.route()`:
       ```python
       def route(self, source_client: str, source_topic: str, message: bytes, ack_fn: Optional[Callable[[], None]] = None, nack_fn: Optional[Callable[[bool], None]] = None, **source_kwargs):
       ```
       - Match routes as before.
       - If no matching routes:
         - If `ack_fn`: call `ack_fn()` (or log unroutable if no DLQ yet).
         - Return.
       - Initialize `coordinator = _FanoutCoordinator(len(matching_routes), ack_fn, nack_fn)` if `ack_fn` or `nack_fn` provided, else None.
       - For each `route_config` in `matching_routes`:
         - Extract `publish_kwargs` (excluding `target_client`, `target_topic`).
         - Merge semantic translations: apply `_translate_semantics(source_kwargs, publish_kwargs)`.
         - If `coordinator`:
           - pass `on_confirm=coordinator.on_confirm` and `on_error=coordinator.on_error`.
         - Call `self.clients[target_client].publish(target_topic, message, **publish_kwargs)`.
         - If `target_client` not in `self.clients`:
           - If `coordinator`: call `coordinator.on_error(ValueError(f"Client {target_client} not registered"))`.
