<task name="harden_plugins" type="auto">
  <files>
    src/postoffice/plugins/mqtt_client.py
    src/postoffice/plugins/amqp_client.py
    src/postoffice/plugins/kafka_client.py
    src/postoffice/plugins/nanomq_client.py
  </files>
  <action>
    1. Update `MqttClient`:
       - Accept `security_config: Optional[Union[SecurityConfig, dict]] = None` in `__init__`.
       - If `security.username`: call `self.client.username_pw_set(security.username, security.password)`.
       - If `security.tls_enabled`:
         - Configure `self.client.tls_set(...)` with `ca_certs`, `certfile`, `keyfile`, and appropriate `cert_reqs`.
         - If `security.insecure_skip_verify`: call `self.client.tls_insecure_set(True)`.
       - Default port to `8883` if `tls_enabled` and `port == 1883`.
    2. Update `AmqpClient`:
       - Accept `security_config: Optional[Union[SecurityConfig, dict]] = None` in `__init__`.
       - If `security.username`: create `pika.PlainCredentials(security.username, security.password)`.
       - If `security.tls_enabled`: create `ssl.SSLContext`, load cert chains, set `verify_mode`, and configure `pika.SSLOptions`.
       - Default port to `5671` if `tls_enabled` and `port == 5672`.
    3. Update `KafkaClient`:
       - Accept `security_config: Optional[Union[SecurityConfig, dict]] = None` in `__init__`.
       - Map to `security.protocol` (`SSL`, `SASL_SSL`, `SASL_PLAINTEXT`).
       - Map `ssl.ca.location`, `ssl.certificate.location`, `ssl.key.location`, `ssl.key.password`.
       - Map `sasl.mechanism`, `sasl.username`, `sasl.password`.
    4. Update `NanoMqClient`:
       - Passes `security_config` to `super().__init__`.
  </action>
  <verify>
    <command>PYTHONPATH=src .venv/bin/python -m unittest discover tests/</command>
  </verify>
</task>
