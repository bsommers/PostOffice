<task name="implement_metrics_manager" type="auto">
  <files>src/postoffice/metrics.py</files>
  <action>
    Create `src/postoffice/metrics.py`:
    1. Define `MetricsManager` with a dedicated `prometheus_client.CollectorRegistry`.
    2. Register collectors:
       - `postoffice_messages_routed_total`: Counter `['source_broker', 'target_broker', 'status']`
       - `postoffice_routing_errors_total`: Counter `['source_broker', 'error_type']`
       - `postoffice_routing_duration_seconds`: Histogram `['source_broker']`
       - `postoffice_dlq_messages_total`: Counter `['source_broker', 'dlq_broker', 'dlq_topic']`
    3. Provide helper recording methods:
       - `record_routed(source_broker, target_broker, status="success")`
       - `record_error(source_broker, error_type)`
       - `record_duration(source_broker, seconds)`
       - `record_dlq(source_broker, dlq_broker, dlq_topic)`
       - `get_metrics_text() -> str`
       - `start_server(port)` and `stop_server()`
  </action>
  <verify>
    <command>PYTHONPATH=src .venv/bin/python -c "from postoffice.metrics import MetricsManager; m = MetricsManager(); m.record_routed('m1', 'k1'); assert 'postoffice_messages_routed_total' in m.get_metrics_text()"</command>
  </verify>
</task>
