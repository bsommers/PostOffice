## Shipped Requirements (v1.1)

### Semantic Translation & Guarantees
- [x] **SEM-01**: Coordinate QoS 1/2 acknowledgements between ingress and egress protocols (wait for Kafka delivery callback or AMQP ack before sending MQTT PUBACK)
  - *Outcome:* Implemented `_FanoutCoordinator` atomic latch in `src/postoffice/router.py` and delivery confirmation callbacks in `src/postoffice/plugins/`. Verified in `tests/test_delivery_guarantees.py`.
- [x] **SEM-02**: Map MQTT QoS levels to AMQP `delivery_mode` (1=transient, 2=persistent) automatically
  - *Outcome:* Implemented `_translate_semantics()` mapping QoS 1/2 to persistent delivery mode 2, and QoS 0 to transient delivery mode 1. Verified in `tests/test_delivery_guarantees.py`.

### Routing Engine Optimization
- [x] **ROUT-01**: Radix / Prefix Trie matching algorithm in `Router` to eliminate O(N) route scan overhead
  - *Outcome:* Created `TopicTrie` in `src/postoffice/trie.py` indexing topics with exact tokens, `+`, and `#` wildcards in $O(k)$ time. Verified with 9 unit tests and benchmark showing 648.9x speedup at 10,000 routes.

### Testing & Reliability
- [x] **TEST-01**: Unit tests for `ControlPlane` and `DataPlane` with mock Redis
  - *Outcome:* Created `tests/test_control_plane.py` (4 tests) and `tests/test_data_plane.py` (5 tests) executing hermetically in milliseconds.
- [x] **TEST-02**: Reconnection resiliency in `DataPlane` if Redis drops connection
  - *Outcome:* Implemented retry backoff loop in `DataPlane.start()` handling unexpected disconnects.
- [x] **TEST-03**: Clean state reset handling in `DataPlane` when `clear_state` is broadcast
  - *Outcome:* Implemented `PostOffice.reset()` and wired into `clear_state` message handler.

### Observability & Error Handling
- [x] **OBS-01**: Metrics instrumentation (counters for messages routed, errors, latency)
  - *Outcome:* Implemented `MetricsManager` in `src/postoffice/metrics.py` with Prometheus collectors and optional HTTP server. Verified in `tests/test_metrics.py`.
- [x] **DLQ-01**: Dead Letter Queue (DLQ) support for unroutable or failed messages
  - *Outcome:* Created `src/postoffice/dlq.py` and wired into `Router` and `PostOffice` with structured JSON envelopes, poison-pill release, and anti-recursion protection. Verified in `tests/test_dlq.py`.
