# Native Phase 0, slice 2: Rust open-loop load generator + sink (MQTT) and HdrHistogram

## Objective
Implement `perf/loadgen/` in Rust (`PERFORMANCE_TEST_PLAN.md` §3):
1. Byte-identical 32-byte `POB1` header and CRC32 (`header.rs`) cross-verified against Python `perf/header.py`.
2. HdrHistogram latency recording (`hist.rs`) with coordinated-omission correction (recording intended send schedule timestamps `t0 + seq * interval_ns` vs actual receive timestamps).
3. MQTT v3.1.1 wire codec and client/sink (`mqtt.rs`) supporting open-loop scheduled publishing, QoS 0/1, and high-rate sink verification with accounting oracle (`sent`, `delivered`, `lost`, `duplicated`, `reordered`, `corrupted`, `foreign`, `unexpected`, `balanced`, `passed`).
4. In-process loopback MQTT broker in `perf/loadgen` for hermetic end-to-end tests (`cargo test -q`) and cross-language verification in `tests/test_perf_loadgen.py`.
