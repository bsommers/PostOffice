# Native Phase 0, slice 3: Bridge-added latency probe, Python worker baseline matrix (P-B), and `docs/BENCHMARKS.md`

## Tasks
1. `perf/probe.py` & `Router.set_latency_probe`: Nanosecond bridge-added latency probe (`time.perf_counter_ns()`) measuring ingress `Router.route()` entry to egress client handoff completion (including `InflightLimiter`, `RetryTracker`, `Firewall`, `TopicTrie`, `SchemaConverter`, and `CircuitBreaker` dispatch). Supports `POSTOFFICE_LATENCY_PROBE=1` env auto-enable.
2. `tests/test_perf_probe.py`: Hermetic unit tests for `LatencyProbe`, `Router.set_latency_probe`, env var activation, and `perf.baseline` scenario execution.
3. `perf/baseline.py`: Python worker T2/P-B benchmark matrix across routes (`MQTT->Kafka`, `MQTT->AMQP`, `AMQP->Kafka`), payload sizes (`64 B`, `1 KB`, `16 KB`), conversions (`passthrough`, `JSON->Avro wire`, `JSON->Protobuf`), fan-out (`1`, `5`, `20`), firewall (`none`, `5-rule`, `5-rule+ContentGuard`), concurrency (`1`, `4`, `8` producer threads to measure GIL serialization), and `10x` overload shedding.
4. `docs/BENCHMARKS.md`: Record full baseline results, SLO comparison table (§0.1 decision gate), and bottleneck breakdown.
