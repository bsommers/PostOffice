## Cross-Phase Integration & E2E Flows

1. **Ingress to Egress Delivery Flow:**
   - Ingress message arrives at `Router.route()`.
   - `TopicTrie` resolves destination routes in $O(k)$ time.
   - `_translate_semantics()` translates QoS 1/2 to persistent AMQP delivery modes.
   - `_FanoutCoordinator` manages publisher confirms across all fanout targets.
   - Upstream broker receives acknowledgement (`ack_fn()`) only after all downstream deliveries succeed.
2. **Failure & DLQ Containment Flow:**
   - If publish fails or times out, `_FanoutCoordinator.dlq_fn` intercepts error.
   - `_route_to_dlq()` formats failure envelope via `format_dlq_payload()`.
   - Message published to per-route or global DLQ; upstream acknowledged to clear poison pill.
   - If recursion detected (message source == DLQ target), message dropped and rejected (`nack_fn(requeue=False)`).
3. **Observability Integration:**
   - Prometheus metrics automatically record every routed message, duration histogram, routing error, and DLQ dispatch.
   - HTTP server cleanly managed by `PostOffice.start()` and `stop()`.
