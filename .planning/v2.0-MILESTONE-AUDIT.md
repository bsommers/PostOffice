## Cross-Phase Integration & E2E Flows

1. **Secure Schema Conversion Flow:**
   - Ingress secure MQTT message arrives over TLS on port 8883.
   - `TopicTrie` resolves destination routes in $O(k)$ time.
   - `SchemaConverter` converts JSON payload to Apache Avro with Confluent 5-byte wire format framing.
   - Converted payload is published to secure Apache Kafka broker over SASL_SSL on port 9094.
   - Acknowledgement propagates back to ingress MQTT client.

2. **Distributed Control & Data Plane Synchronization:**
   - Security configurations registered via `ControlPlane.register_broker()` are serialized to JSON in Redis.
   - `DataPlane` workers receive Pub/Sub notifications, deserialize `SecurityConfig`, and connect secure broker instances dynamically.
